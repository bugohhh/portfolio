## 背景

管理科學課的作業：一家公司（LLC）需要決定每個時段要安排多少人力，在滿足人力需求的前提下讓成本最低。這類問題人工排很容易漏掉限制，適合寫成數學模型交給求解器。

## 我做了什麼

- 定義決策變數、目標函數與限制式，把文字描述的問題轉成整數規劃（IP）模型
- 用數學符號寫出完整模型
- 用 Python 的 `gurobipy` 實作並求解，再檢查結果是否符合所有限制

## 技術重點

### 從文字到模型

最花時間的是建模，不是寫程式。要先想清楚：決策變數是什麼？哪些條件是硬性限制？人數必須是整數，所以是整數規劃而不是線性規劃。

### Big-M 線性化

有些限制是「如果…就…」的邏輯條件，不能直接寫成線性式。這時用 Big-M 方法搭配 0/1 變數，把條件式轉成求解器能處理的線性限制，在 gurobipy 裡的寫法大致如下（示意）：

```python
m.addConstr(x[t] <= M * y[t])  # 沒有開班 (y=0) 就不能排人
```

## 反思

同一學期也用 `scipy` 做過投資組合最佳化（效率前緣）。兩次作業讓我發現，最佳化的關鍵在於能不能把現實問題翻譯成正確的數學式，求解器只是最後一步。

> 模型寫錯，求解器只會很有效率地給你錯的答案。
